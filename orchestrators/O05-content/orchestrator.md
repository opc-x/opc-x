# O05 · Content · 内容部

> 负责所有对外文字输出，是螺旋协议「执行」阶段的内容侧。

**触发关键词**：文章 / 文案 / 文档 / 社交 / 邮件 / 脚本 / SEO / newsletter

---

## 技能索引

| ID | 技能 | 何时用 |
|---|---|---|
| S01 | 博客文章 | 需要深度内容建立权威时 |
| S02 | 营销文案 | 产品页 / 广告 / 落地页文案时 |
| S03 | 技术文档 | 开发者文档 / 使用说明时 |
| S04 | 社交媒体 | 日常运营 Twitter/微博/LinkedIn 时 |
| S05 | 邮件序列 | 用户激活 / 留存 / 促销时 |
| S06 | 视频脚本 | 产品演示 / 教程视频时 |
| S07 | SEO优化 | 提升搜索排名时 |
| S08 | 标题测试 | 优化点击率时 |
| S09 | 案例研究 | 需要用真实案例建立信任时 |
| S10 | 订阅通讯 | 定期维护邮件列表时 |

## 常用技能链

### 产品发布内容
`S02` → `S08` → `S04` → `S10`
营销文案 → 标题测试 → 社交媒体发布 → 通讯推送

### SEO 内容矩阵
`S07` → `S01` → `S08`
SEO关键词规划 → 博客文章 → 标题A/B测试

### 用户教育体系
`S03` → `S01` → `S09`
技术文档 → 博客文章 → 案例研究

### 用户留存邮件
`S05` → `S08`
邮件序列设计 → 标题测试优化

## Issue 协议

**Label**：`O05-content`
**激活时读**：`gh issue list --label O05-content --state open`
**创建条件**：内容生产任务确认（文案 / 文章 / 文档 / 社交帖子 / 邮件序列）
**标题格式**：`[O05] {内容类型：描述}`
**Cursor接单**：⚠️（文档 / 代码注释 / README 更新可派 Cursor；营销文案由 Claude 处理）
