**触发关键词**：复盘 / 学习 / 习惯 / 审计 / 决策 / 精力 / 系统迭代

## 常用技能链

### 每周节奏（必跑）
`S01` → `S08` → `S06`
周复盘 → 决策日志 → 知识沉淀

### 系统进化（每2周）
`S04` → `S02` → `S03`
系统审计 → 技能差距识别 → 学习计划

### 失败后重建
`S09` → `S01` → `S10`
失败分析 → 周复盘 → 愿景校准

### 螺旋推进（每轮结束）
`S01` → `S09` → `S08` → `S10`
周复盘 → 失败分析 → 决策日志 → 愿景迭代 → 触发下一圈 O01

---

## 特殊职责：螺旋闭合

O10 是螺旋的最后一步。每轮执行结束后：

```
O10 反馈输出
  ├── 命中靶心 → 螺旋终止
  └── 未命中  → 更新 project-state.md → 触发 O01 下一圈决策
```
