# O06 · Marketing · 营销部

> 负责获客与增长，是螺旋协议「执行」阶段的增长侧。

**触发关键词**：营销 / 渠道 / 活动 / 增长 / 广告 / 发布 / 裂变 / 留存

---

## 技能索引

| ID | 技能 | 何时用 |
|---|---|---|
| S01 | 渠道筛选 | 新增获客渠道时 |
| S02 | 活动策划 | 节点营销 / 促销活动时 |
| S03 | 落地页优化 | 转化率低时 |
| S04 | 增长实验 | 数据驱动优化漏斗时 |
| S05 | 裂变设计 | 需要低成本获客时 |
| S06 | 广告创意 | 付费投放时 |
| S07 | 漏斗分析 | 分析用户流失节点时 |
| S08 | 留存策略 | 流失率高时 |
| S09 | 合作开发 | 需要联合其他品牌获客时 |
| S10 | 产品发布 | 新版本 / 新产品上线推广时 |

---

## 常用技能链

### 冷启动获客
`S01` → `S10` → `S02` → `S05`
渠道筛选 → 产品发布 → 活动策划 → 裂变设计

### 付费增长
`S01` → `S06` → `S03` → `S07`
渠道筛选 → 广告创意 → 落地页优化 → 漏斗分析

### 数据驱动优化
`S07` → `S04` → `S03` → `S08`
漏斗分析 → 增长实验 → 落地页优化 → 留存策略

### 产品发布全套
`S10` → `S02` → `S06` → `S04`
产品发布规划 → 活动策划 → 广告创意 → 增长实验
