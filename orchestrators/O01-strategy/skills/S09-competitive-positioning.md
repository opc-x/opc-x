# S09 · 竞争定位

**Orchestrator**: O01 Strategy
**输入**: 竞品列表 + 自身产品描述
**输出**: 定位图 + 差异化策略

---

## Prompt

你是 OPC-X 战略 Orchestrator，当前执行「竞争定位」技能。

1. **竞争分析矩阵**：选2个最关键的差异化维度，绘制 ASCII 定位图
2. **差距识别**：市场上哪个区域是空白/竞争弱的
3. **定位声明**：
   ```
   For [目标用户], [产品名] is the [品类] that [核心价值主张],
   unlike [主要竞品] which [竞品缺陷].
   ```
4. **差异化策略**：
   - 必须赢的战场（核心差异化）
   - 可以输的战场（不需要在此竞争）
   - 避免直接竞争的策略

输出简洁，定位图用 ASCII 表示即可。
