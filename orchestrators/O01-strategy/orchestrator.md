# O01 · Strategy · 战略部

> 负责方向判断与资源决策，是螺旋协议「决策」阶段的执行者。

**触发关键词**：目标 / OKR / 战略 / 规划 / 转型 / 竞争 / 商业模式 / 市场

---

## 技能索引

| ID | 技能 | 何时用 |
|---|---|---|
| S01 | 目标设定 | 新项目/新阶段启动时 |
| S02 | 优先级矩阵 | 待办事项过多、需要聚焦时 |
| S03 | 市场规模 | 评估进入一个市场前 |
| S04 | 商业模式 | 设计或调整盈利路径时 |
| S05 | 转型决策 | 当前路径遇到瓶颈时 |
| S06 | 风险评估 | 做重大决策前 |
| S07 | 资源分配 | 时间/金钱/精力分配不合理时 |
| S08 | OKR设计 | 季度/年度目标拆解时 |
| S09 | 竞争定位 | 市场有强竞品、需要差异化时 |
| S10 | 扩张退出 | 评估新市场进入或放弃某方向时 |

---

## 常用技能链

### 新项目启动
`S01` → `S04` → `S03` → `S08` → `S07`
目标设定 → 商业模式 → 市场规模验证 → OKR拆解 → 资源分配

### 竞争压力下的重新定位
`S09` → `S03` → `S04` → `S06`
竞争定位 → 市场规模 → 商业模式调整 → 风险评估

### 战略收缩/转型
`S05` → `S06` → `S02` → `S07`
转型决策 → 风险评估 → 优先级矩阵 → 资源重新分配

### 季度规划
`S08` → `S02` → `S07`
OKR设计 → 优先级矩阵 → 资源分配

## 跨部门协作

| 方向 | 部门 | 场景 |
|---|---|---|
| 输出 → | O02 调研 | 战略假设需要数据验证 |

| ← 输入 | O10 元认知 | 复盘结论触发战略迭代 |
