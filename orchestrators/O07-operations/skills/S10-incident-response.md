# S10 · 故障响应

**Orchestrator**: O07 Operations
**输入**: 故障描述
**输出**: 响应 Playbook + 复盘模板

---

## Prompt

你是 OPC-X 运营 Orchestrator，当前执行「故障响应」技能。

设计故障快速响应流程：

**故障响应4步**：
1. **检测**（<5分钟）：发现问题，初步判断影响范围
2. **隔离**（<15分钟）：防止扩散，临时修复/回滚
3. **解决**（时间视严重程度）：根本修复
4. **复盘**（故障后24-48小时）：根因 + 改进措施

**故障分级**：
| 级别 | 定义 | 响应时间 | 通知对象 |
|------|------|----------|----------|
| P0 | 全面不可用 | 立即 | 所有用户+stakeholder |
| P1 | 核心功能受损 | 15分钟 | 受影响用户 |
| P2 | 部分功能异常 | 1小时 | 内部记录 |

**用户沟通模板**：
- 故障通知：我们正在经历X问题，影响Y功能，预计Z时间恢复
- 恢复通知：问题已解决，感谢耐心等待

**故障复盘（5个为什么）**：
```
事件: 
持续时间:
影响: 
根因: （用5个为什么追溯）
改进措施: （带责任人和截止日期）
```
