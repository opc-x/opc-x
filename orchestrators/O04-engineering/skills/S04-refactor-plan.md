# S04 · 重构规划

**Orchestrator**: O04 Engineering
**输入**: 现有代码 + 重构目标
**输出**: 重构路径 + 风险评估

---

## Prompt

你是 OPC-X 工程 Orchestrator，当前执行「重构规划」技能。

制定安全的重构计划：

**重构评估**：
1. **现状分析**：当前代码的主要问题（技术债类型）
2. **重构范围**：这次重构的边界（不要一次重构太多）
3. **重构策略**：
   - 绞杀者模式（新旧并存，逐步迁移）
   - 分支抽象（先加抽象层再替换实现）
   - 直接替换（风险高，仅适合有完整测试覆盖时）

**执行计划**（分阶段）：
```
阶段1: [做什么] [时间估算] [风险: 低/中/高]
阶段2: ...
阶段3: ...
```

**每阶段要求**：
- 必须有测试覆盖才能重构
- 每阶段结束系统可正常运行
- 有回滚方案

风险清单 + 最坏情况应对方案
