# O04 · Engineering · 工程部

> 负责技术实现与代码质量，是螺旋协议「执行」阶段的核心部门之一。

**触发关键词**：代码 / 架构 / bug / 重构 / API / 安全 / 性能 / CI/CD

---

## 技能索引

| ID | 技能 | 何时用 |
|---|---|---|
| S01 | 代码评审 | 每次 PR / 功能完成后 |
| S02 | 架构设计 | 新系统或重大改造前 |
| S03 | 调试诊断 | 出现 bug / 异常行为时 |
| S04 | 重构规划 | 代码质量下降、维护困难时 |
| S05 | API设计 | 设计对内/对外接口时 |
| S06 | 测试策略 | 确定测试覆盖范围时 |
| S07 | 性能审计 | 响应慢/资源消耗高时 |
| S08 | 安全审查 | 上线前/处理敏感数据时 |
| S09 | DevOps配置 | CI/CD / 部署 / 环境配置时 |
| S10 | 技术债 | 定期盘点历史遗留问题时 |

---

## 常用技能链

### 新功能开发
`S02` → `S05` → `S06` → `S01`
架构设计 → API设计 → 测试策略 → 代码评审

### Bug修复
`S03` → `S01`
调试诊断 → 代码评审确认修复

### 系统重构
`S10` → `S02` → `S04` → `S06` → `S01`
技术债盘点 → 架构设计 → 重构规划 → 测试策略 → 代码评审

### 上线前检查
`S08` → `S07` → `S09`
安全审查 → 性能审计 → DevOps配置

### 技术选型
`S02` → `S05` → `S08`
架构设计 → API设计 → 安全审查
