# O09 · Finance · 财务部

> 负责数字健康与商业可行性，支撑所有涉及钱的决策。

**触发关键词**：定价 / 收入 / 财务 / 现金流 / 合同 / 融资 / CAC / LTV

## 常用技能链

### 定价决策
`S06` → `S01` → `S02` → `S09`
单位经济学 → 定价策略 → 收入预测 → 财务模型验证

### 融资准备
`S09` → `S07` → `S02` → `S08`
财务模型 → 现金流 → 收入预测 → 融资材料

### 日常运营财务
`S03` → `S07` → `S05`
支出追踪 → 现金流更新 → 税务规划

### 新合作/供应商
`S10` → `S03`
合同审查 → 支出追踪更新
