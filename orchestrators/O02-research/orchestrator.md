# O02 · Research · 调研部

> 负责在决策前收集和合成外部信息，是战略与产品的情报支撑。

**触发关键词**：调研 / 竞品 / 用户洞察 / 趋势 / 问卷 / 数据来源

---

## 技能索引

| ID | 技能 | 何时用 |
|---|---|---|
| S01 | 竞品分析 | 进入新市场或竞争加剧时 |
| S02 | 用户访谈 | 需要定性洞察时 |
| S03 | 趋势扫描 | 判断行业方向时 |
| S04 | 文献综述 | 进入陌生领域需要系统了解时 |
| S05 | 问卷设计 | 需要定量数据时 |
| S06 | 数据来源 | 找不到可靠数据时 |
| S07 | 洞察合成 | 把多个来源的信息整合成结论时 |
| S08 | 用户画像 | 需要具象化目标用户时 |
| S09 | JTBD分析 | 理解用户真实需求动机时 |
| S10 | 行业标杆 | 寻找最佳实践时 |

---

## 常用技能链

### 用户研究全链路
`S05` → `S02` → `S08` → `S09` → `S07`
问卷设计 → 用户访谈 → 用户画像 → JTBD分析 → 洞察合成

### 竞品深度研究
`S01` → `S10` → `S07`
竞品分析 → 行业标杆 → 洞察合成

### 新领域快速了解
`S04` → `S03` → `S06` → `S07`
文献综述 → 趋势扫描 → 数据来源 → 洞察合成

### 定价/市场调研
`S05` → `S06` → `S01` → `S07`
问卷设计 → 数据来源 → 竞品分析 → 洞察合成
